# Image target

Versi demo memakai kartu contoh resmi MindAR melalui CDN.

Untuk menggantinya dengan gambar Rafflesia:

1. Siapkan gambar detail, kontras, dan tidak terlalu simetris.
2. Buka [MindAR Image Target Compiler](https://hiukim.github.io/mind-ar-js-doc/tools/compile/).
3. Unggah gambar dan unduh `targets.mind`.
4. Simpan gambar dan `targets.mind` di folder ini.
5. Ubah `imageTargetSrc` di `public/ar/index.html` menjadi `/targets/targets.mind`.

Gunakan cetakan matte atau tampilkan gambar pada perangkat kedua saat menguji.
