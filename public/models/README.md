# Model 3D

Letakkan model produksi di folder ini dengan format `.glb`, misalnya `rafflesia.glb`.

- Targetkan ukuran file di bawah 5 MB.
- Gunakan tekstur maksimal 2048 × 2048 px.
- Letakkan pivot model di bagian bawah/tengah objek.
- Uji performa pada ponsel Android kelas menengah.

Demo saat ini memakai bunga procedural dari primitive A-Frame, sehingga berjalan tanpa model eksternal.
